# 🧬 NanoApps | Dev2Bless

Bem-vindo ao **NanoApps**, um repositório curado pela **Dev2Bless** dedicado a aplicações de arquivo único (*Single-File Apps*). 

A filosofia aqui é a **simplicidade extrema**: ferramentas úteis, leves e totalmente autocontidas em um único arquivo `.html` (incluindo CSS e JS internamente). Sem dependências externas complexas, sem builds pesados — basta baixar e abrir no navegador.

## 🛠️ Como usar?

Existem duas formas principais de utilizar os NanoApps deste repositório:

1. **Uso Local:** - Faça o download do arquivo `.html` desejado.
   - Clique duas vezes no arquivo para abrir no seu navegador preferido.
2. **Via GitHub Pages:**
   - Se o repositório estiver com o Pages ativo, você pode acessar diretamente pela URL: `https://dev2bless.github.io/nanoapps/NomeDoApp.html`.

## 🎨 Padrão de Desenvolvimento

Para manter a consistência dos NanoApps, seguimos estas diretrizes:

* **Arquivo Único:** Todo o código (HTML, CSS e JavaScript) deve residir em um único arquivo.
* **Zero Dependências:** Preferência por Vanilla JS e CSS puro. Caso use bibliotecas externas (como Tailwind via CDN), garanta que o link esteja funcional.
* **Responsividade:** O app deve ser utilizável tanto em Desktop quanto em Mobile.
* **Persistência:** Para apps que exigem salvar dados (como o NanoReis), utilizamos o `localStorage` do navegador.
